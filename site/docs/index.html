Lantern

A tiny miner, a dying lamp, and a very deep hole.

Play the game · Source on GitHub · CLAUDE.md

Concept

The miner digs down a shaft one screen at a time. Lamp oil drains constantly, and the circle of light around the miner shrinks with it. Gems give points and are worth more the deeper you go. Oil cans refill the lamp. The tension is whether to dig deeper for better gems or stay near the oil. At zero oil the game shows "lamp out" with the final depth and score, then restarts on a button press.

Project structure

lantern.p8                    the whole game: code, sprites, sound
tools/export.sh               rebuilds site/ from the cart
tools/make-icon.py            draws the web icons in site/
site/index.html, index.js     the committed web export
site/cart.sha256              hash of the cart that site/ was built from
site/docs/index.html          this page
.github/workflows/deploy.yml  publishes site/ to GitHub Pages

The __lua__ section runs in order: constants, init/reset, level generation, update (player, bats, popups), draw (world, darkness, HUD, game over), and small helpers. The code is heavily commented on purpose. It doubles as a way to learn PICO-8.

Tiles and sound

The sprite number is the tile id, so map() draws the level directly.

SpriteUse
0, 1, 2Empty, dirt, rock
3, 4, 5Green, blue and red gems
6Oil can
7-8, 11Miner walking, miner aiming down
9-10Bat flapping

Sound effects: 0 dig, 1 gem, 2 oil, 3 bat hit, 4 lamp out, 5 rock clunk.

Level generation

Each screen is built at runtime with mset, so the cart's map section is unused. Play covers map cells (0,0) to (15,14), drawn 8px down to leave room for the HUD. Falling off the bottom generates the next screen.

Rocks may stack vertically but never touch another rock sideways or diagonally. That guarantees the miner can always step aside and dig down, so never break this rule when tweaking generation.

Deployment

GitHub Actions can't run PICO-8 because it's a licensed binary, so the web export is built locally and committed. PICO-8's licence allows exported HTML and JavaScript to be redistributed. 

tools/export.sh                  # rebuild site/ from lantern.p8
git add -A && git commit         # include the new export
git push                         # main deploys to GitHub Pages

Every push to main publishes site/. The workflow fails if lantern.p8 no longer matches site/cart.sha256, which means the export step was skipped. The live game is at polarispixels.github.io/lantern/.
